# Normy budowlane – Gdańsk

Nawigator po 17 aktach prawa budowlanego istotnych dla projektów w Gdańsku (ustawy, rozporządzenia, uchwały Rady Miasta Gdańska):

- podział każdego aktu na jego własne działy, rozdziały i załączniki,
- tekst jednostek redakcyjnych w brzmieniu oryginalnym,
- zmiany względem poprzedniej redakcji (tekst jednolity vs tekst jednolity lub akt zmieniający),
- daty aktualności i status obowiązywania.

Źródła: Dziennik Ustaw (ISAP/ELI), Dziennik Urzędowy Województwa Pomorskiego. Stan sprawdzenia: 11.11.2026.

Materiał roboczy o charakterze analitycznym – nie stanowi opinii prawnej.
